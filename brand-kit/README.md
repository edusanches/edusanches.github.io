# Brand kit — Eduardo Sanches

Base reutilizável para capas e futuros materiais da identidade visual do site.

## Gerador

O arquivo `generators/social-covers.html` concentra o fundo, a paleta, o grão e a tipografia das capas.

- YouTube: `social-covers.html?format=youtube`
- YouTube com safe area: `social-covers.html?format=youtube&guides=1`
- X: `social-covers.html?format=x`
- X com área de composição: `social-covers.html?format=x&guides=1`

## Arquivos

- `exports/youtube/youtube-banner.png`: versão pronta para upload, 2560 × 1440.
- `source-renders/youtube/youtube-banner-source.png`: renderização full color para reutilização.
- `previews/youtube-safe-area.png`: prévia com a safe area central de 1546 × 424.
- `exports/x/x-cover.png`: versão pronta para upload, 1500 × 500.
- `source-renders/x/x-cover-source.png`: renderização full color para reutilização.
- `previews/x-content-area.png`: prévia com a margem de composição usada no layout.
- `archive/`: versões anteriores preservadas.

As versões em `source-renders` não são otimizadas para upload. Elas ficam preservadas para gerar novas peças sem recomprimir o material-base.
